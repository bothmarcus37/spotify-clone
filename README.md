# Clon de Spotify

Buscador de música que usa la API de búsqueda de iTunes. Proyecto académico, sin relación con Spotify.

## Qué hace
- Busca por artista, canción o álbum y muestra portada, artista y álbum.
- Reproduce un fragmento de 30 segundos en un reproductor fijo, con pausa y barra de avance.
- Guarda tus canciones favoritas en "Biblioteca" (se conservan en el navegador con `localStorage`).
- Búsquedas sugeridas para empezar.
- Se adapta a celular.

## Cómo ejecutarlo
Abre `index.html` en el navegador. No necesita servidor ni claves.

## Hecho con
HTML, CSS y JavaScript con Fetch API.
